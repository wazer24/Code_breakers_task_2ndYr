## 🎨 Design Elements

### Glass Morphism Effect
- Semi-transparent dark background
- Backdrop blur effect
- Subtle border
- Shadow on hover

### Gradient Text
- Cyan to Purple gradient
- Smooth transition
- Used for headings and CTAs

### Button Styles

**Primary Button**:
- Gradient background (cyan → purple)
- White text
- Shadow glow on hover
- Slight lift animation

**Secondary Button**:
- Dark gray background
- Gray border
- White text
- Border glow on hover

**Outline Button**:
- Transparent background
- Gradient border
- Gradient text

### Card Animations
- Fade in from bottom on scroll
- Scale up on hover
- Shadow increases on hover
- Smooth 300ms transitions

### Icons
- Lucide React icon library
- Consistent size (typically 24px)
- Gradient backgrounds in feature cards
- White fill

---

## 📱 Responsive Breakpoints

### Mobile (< 640px)
- Single column layouts
- Hamburger menu
- Stacked cards
- Full-width buttons

### Tablet (640px - 1024px)
- 2-column grids
- Collapsible menu (varies)
- Side-by-side cards
- Adjusted spacing

### Desktop (> 1024px)
- 3-column grids
- Full horizontal menu
- Maximum content width: 1280px
- Optimal spacing

---

## ✨ Animation Types

1. **Scroll Animations**
   - Fade in + slide up
   - Triggered when entering viewport
   - Staggered delays for lists

2. **Hover Effects**
   - Scale transform
   - Shadow increase
   - Border glow
   - Color transitions

3. **Background Animations**
   - Floating gradient orbs
   - Slow pulse effect
   - Parallax-like movement

4. **Form Interactions**
   - Input focus border glow
   - Button press feedback
   - Success state animations

---

## 🎯 Key Visual Principles

1. **Dark First**: Dark backgrounds with light text
2. **Gradient Accents**: Cyan/purple for emphasis
3. **Depth**: Glass effects and shadows for depth
4. **Motion**: Subtle animations for engagement
5. **Consistency**: Repeating patterns across pages
6. **Spacing**: 8px grid for harmony
7. **Typography**: Clear hierarchy with Poppins/Inter
